### Project Objective

Design and implement the control system of an elevator, combining real-time software development and hardware design in VHDL.

### Achievements

**Software part (STM32 / RTOS):**

- Created and managed tasks (fnTacheCabine, tacheGestionLED).
- Implemented real-time scheduling to control cabin movement and LED display.

**Hardware part (FPGA / VHDL):**

- Designed control logic for the elevator.
- Implemented control and synchronization signals.

### Skills Developed

- Embedded programming (C on STM32).
- Use of a real-time operating system (multitasking management).
- VHDL for hardware description.
- Teamwork and technical project management.
